# 16일 시장 동선 및 일자별 흐름 카드 설계

## 목표

8월 16일 일정을 부산역 도착 후 남포와 초량을 잇는 가족 여행 동선으로 재구성한다. 점심은 이재모피자, 체험은 부산과학체험관으로 고정하고, 초량전통시장과 부평깡통시장을 모두 방문한다. 초량에서는 가벼운 시장 탐방과 간식을, 부평깡통시장에서는 정식 저녁과 야시장 탐방을 맡는다.

같은 화면의 일자별 흐름 입력은 날짜마다 경계가 명확한 카드로 묶어, 인접 날짜의 일정·추가 요청·권역 입력과 혼동되지 않게 한다.

## 확정 동선

`부산역 도착 → 아스티호텔 짐 보관 → 이재모피자 점심 → 부산과학체험관 → 초량전통시장 탐방·간식 → 부평깡통시장 저녁·야시장 → 아스티호텔`

- 이재모피자는 남포권에서 점심으로 배치하고, 대기 시간을 고려한 뒤 과학체험관으로 이동한다.
- 초량전통시장은 과학체험관 인근의 짧은 탐방 구간이다. 어묵, 만두, 튀김 등 간식 중 한두 가지만 선택하며 정식 식사 블록은 만들지 않는다.
- 부평깡통시장은 저녁 목적지다. 야시장 운영 시간과 매장 휴무는 출발 전에 재확인하도록 안내한다.
- 저녁 후보는 양산집(돼지국밥), 깡통골목할매 유부전골(유부전골), 부평통닭(시장 통닭)으로 제공한다. 선택된 예산 타입에는 이 중 하나만 정식 저녁으로 반영한다.
- 초량의 식사 후보는 탐색용 정보로만 제공한다. 손가네맛집(장어숯불구이), 초량통닭, 벌교집(국밥·국류)을 후보 목록에 유지하되, 16일 기본 식사에 자동 삽입하지 않는다.

## 데이터 변경

- `defaultBlocks[2026-08-16]`를 도착·짐 보관, 이재모피자, 부산과학체험관, 초량시장 탐방, 부평깡통시장 저녁, 호텔 복귀 순으로 교체한다.
- `routeSequences`, `mapRoutePoints`, `places`, `mapPlaceCatalog`에 이재모피자, 부산과학체험관, 초량전통시장, 부평깡통시장을 추가하고 해당 순서로 연결한다.
- `mealSlots`, `mealSelections`, `mealPriorities`를 갱신해 모든 예산 타입에서 이재모피자 점심과 서로 다른 장르의 부평 저녁을 선택한다. 여행 전체에서 기본 식사 장르가 중복되지 않는 기존 규칙을 유지한다.
- 롯데월드 부산은 `defaultBlocks`, 활동 후보, 예산 플랜, 지도 경로와 장소 목록에서 모두 제거한다. 18일은 국립부산과학관, 스카이라인 루지(맑은 날), 오시리아 휴식 및 기장 또는 광안리 저녁으로 유지한다.

## UI 변경

- 일자별 흐름 편집기는 날짜마다 독립된 `day-flow-card`를 렌더링한다.
- 카드 상단에는 날짜와 해당 일자의 흐름 요약을 두고, 본문에 `일정`, `추가 요청`, `권역` 행을 배치한다.
- 테두리, 충분한 행 간격, 모바일에서는 세로 배치를 적용한다. 기존 입력 저장, 날짜별 한 건 제한, 자동 재배치 동작은 바꾸지 않는다.
- 카드 내부의 레이블과 입력은 연결되어 보조기술에서도 날짜별 맥락을 잃지 않는다.

## 오류 처리와 재확인

- 이재모피자 대기, 과학체험관 운영, 부평 야시장 운영 및 각 식당 휴무는 일정 확정 전 외부 링크로 재확인하도록 표기한다.
- 부평 저녁 후보가 휴무이면 같은 예산 타입 안에서 장르가 겹치지 않는 다음 후보를 선택하고, 재계산 결과에 선택 사유를 표시한다.
- 16일의 시장 탐방은 추가 요청과 별개인 기본 일정이므로, 사용자가 추가 요청을 넣어도 한 건 제한과 빈 시간 자동 배치 규칙을 그대로 적용한다.

## 검증

- 데이터 테스트: 16일 기본 블록, 지도 경로, 선택 식사가 확정 순서와 일치하는지 검증한다.
- 회귀 테스트: 롯데월드 부산 문자열 및 관련 경로가 일정·지도·예산 결과에서 노출되지 않는지 검증한다.
- 식사 테스트: 알뜰·균형·여유 각각에서 이재모피자 점심과 부평 저녁이 선택되고, 전체 기본 식사 장르가 중복되지 않는지 검증한다.
- UI 테스트: 네 날짜가 각각 하나의 흐름 카드로 렌더링되고, 카드별로 일정·추가 요청·권역 입력이 존재하는지 검증한다.
- 빌드 및 E2E: 기존 전체 일정 재계산, 예산 타입 전환, 탐색 지도 경로가 변경된 16일 데이터와 함께 정상 동작하는지 확인한다.
