# 부산 Tokidoki 여행 총괄 에이전트 작업 계획

상세 실행 계획은 [superpowers 계획서](../superpowers/plans/2026-08-07-busan-trip-agent-rebuild.md)를 기준으로 진행한다.

## 목표

- Tokidoki의 탭형 정적 여행 앱 구성을 부산 여행에 맞게 재구축한다.
- 일자별 흐름을 입력하면 일정, 동선, 숙소, 교통, 식당/맛집, 놀거리 에이전트가 재계산된다.
- 총괄 에이전트가 에이전트 간 충돌과 시간 부족을 검증하고 경고한다.

## 고정 조건

- 16일 서울역 07:58 출발, 부산역 10:46 도착
- 19일 부산역 14:31 출발, 서울역 17:14 도착
- 16~17일 아스티호텔 부산
- 17~19일 파라다이스호텔 부산
- 17일 해운대 관광과 물놀이
- 18일 오시리아 등 부산 내 다른 체험/휴식/식사 권역
- 19일 오전 씨메르
